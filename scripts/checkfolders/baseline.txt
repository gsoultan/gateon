# Packages over arch's ten-file limit, pinned at the size they had when the
# ratchet landed on 2026-09-03. Format: "<count> <path>".
#
# These are debt, not exemptions. Each line is a ceiling: the package may shrink
# and the line must then be lowered in the same commit, but it may not grow. New
# code that would push one of these up belongs in a package of its own.
#
# Do not add a line here to make a failure go away. A tenth package crossing the
# limit is the check working — it means a package grew past the size a reader can
# hold in their head, and the answer is to split it while it is still nine files
# of drift rather than sixty.

# What is left of the request-path middleware chain after ADR-0002 drained it:
# the Factory, the chain assembly in standard.go, and the handful of
# middlewares that are neither traffic, transform nor security -- realip,
# forwardedheaders, circuit_breaker, otel. Twelve rather than ten because the
# remaining two seams are small and not obviously worth their own package:
# realip.go and forwardedheaders.go are one client-identity concern, and
# circuit_breaker.go is a resilience concern with nothing yet to join it.
# Down from sixty-seven when the ratchet landed.
12 internal/middleware

# ADR-0002's traffic stage, landed 2026-09-20. Thirteen files rather than ten
# because the ADR names this group as one unit -- ratelimit, connlimit, maxbody,
# inflight, retry, cache and compress are the traffic-shaping concern, and
# splitting it further would be a structural change the ADR does not describe.
# If it grows, cache is the obvious next seam: cache.go, cache_factory.go,
# cache_redis.go and cache_store.go are four files that already sit together.
13 internal/middleware/traffic

# ADR-0002's transform stage, landed 2026-09-20. Twelve files for the same
# reason traffic has thirteen: the ADR names cors, headers, rewrite, xfcc,
# grpcweb and wasm as one request/response-transform group, and splitting it
# again is a structural change the ADR does not describe. cors is the seam if
# it grows -- cors.go, cors_factory.go and cors_presets.go already sit together.
12 internal/middleware/transform

# ADR-0002's security stage, landed 2026-09-20, after the WAF cluster was
# extracted from it in the following commit. Twenty-four files rather than ten
# because this pin is the ADR admitting its own partition was wrong: it named
# "security" as one stage, and moving it showed the group is five concerns that
# share an adjective -- the challenge middlewares (pow, turnstile, bot
# management), fingerprint identity (tls_fingerprint, tls_binding, reputation,
# ip_mitigation), network access (geoip, ipfilter, policy), API-shape
# validation (openapi, schema_validation, graphql_firewall) and content
# inspection (file_security, deception, honeypot).
#
# Splitting it five further ways is a structural change ADR-0002 does not
# describe and should not be folded into it; the WAF extraction was, because
# the ADR named it. Fingerprint identity is the next seam on the same evidence
# the WAF had: reputation.go, tls_fingerprint.go, tls_binding.go and
# ip_mitigation.go are one concern that nothing else in the package reaches
# into.
24 internal/middleware/security
