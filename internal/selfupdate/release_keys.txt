# The Ed25519 public keys gateon release lists are signed with, one base64 key
# per line. The gateway accepts a release whose checksums.txt.sig verifies
# under any of them; with no key here it can verify nothing, and says so.
#
# Add one with:   go run ./scripts/releasesign keygen -out <private key file>
# and store the private half as the GATEON_RELEASE_SIGNING_KEY secret. See
# doc/releasing.md. Two lines are a rotation: sign with the new key, and drop
# the old line once every supported version carries the new one.
